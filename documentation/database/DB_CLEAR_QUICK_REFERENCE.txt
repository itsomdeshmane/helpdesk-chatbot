╔══════════════════════════════════════════════════════════════════════╗
║ SCRIPT COMPARISON                                                    ║
╚══════════════════════════════════════════════════════════════════════╝

┌─ quick_clear_db.py ────────────────────────────────────────────────┐
│ • Simple and fast                                                   │
│ • Clears only chat history                                          │
│ • Keeps entities and structure                                      │
│ • Safe for regular use                                              │
│                                                                     │
│ Usage: python quick_clear_db.py --yes                               │
└─────────────────────────────────────────────────────────────────────┘

┌─ clear_database.py ────────────────────────────────────────────────┐
│ • Full control                                                      │
│ • Multiple options (delete/truncate/drop)                           │
│ • Can preserve entities                                             │
│ • Shows detailed status                                             │
│                                                                     │
│ Usage: python clear_database.py [options]                           │
└─────────────────────────────────────────────────────────────────────┘

╔══════════════════════════════════════════════════════════════════════╗
║ OPTIONS EXPLAINED                                                    ║
╚══════════════════════════════════════════════════════════════════════╝

--status           Show what's in the database
--clear            Clear all data from tables
--truncate         Use TRUNCATE (faster than DELETE)
--drop             Drop and recreate all tables
--keep-entities    Don't clear erp_entities table
--yes, -y          Skip confirmation prompt
