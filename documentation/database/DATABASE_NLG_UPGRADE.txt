================================================================================
HOW IT WORKS
================================================================================

Step 1: Analyze Query
---------------------
The system analyzes the user's natural language query to determine:
- What type of query it is (count, sum, list, etc.)
- What subject they're asking about (customers, orders, products, etc.)
- Any location context (in India, from USA, etc.)

Step 2: Execute SQL
------------------
Generate and execute the SQL query against the database.

Step 3: Generate Natural Language
--------------------------------
Based on the query type, subject, and location:
- Select appropriate response template
- Format numbers with separators
- Use correct singular/plural forms
- Include contextual information
- Make it sound natural and conversational

Step 4: Return Result
--------------------
Combine the natural language summary with the data table.

EXAMPLES OF SMART FEATURES

Feature: Subject Extraction
--------------------------
Query: "How many customers do we have in India?"

Feature: Number Formatting
-------------------------
Raw Result: 125000
Formatted: "125,000"

Raw Result: 1250.50
Formatted: "1,250.50"

Feature: Singular/Plural
-----------------------
1 result → "I found 1 customer"
5 results → "I found 5 customers"
1 result → "I found 1 order"
10 results → "I found 10 orders"

Feature: Contextual Verb Choice
------------------------------
Count = 1 → "is"
Count > 1 → "are"

Example: "Total available customer is 1."
Example: "Total available customers are 25."

Feature: Additional Details for Max/Min
--------------------------------------
Query: "What is the highest sales?"
Result has multiple columns:
Response: "The highest sales is 50,000 (customer: John Doe, region: USA)."
