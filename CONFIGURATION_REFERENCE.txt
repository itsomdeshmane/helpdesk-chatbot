SECTION 9: QUICK SETUP CHECKLIST
================================================================================

Python Backend Setup:
□ Copy backend/env.template to backend/.env
□ Set OPENAI_API_KEY
□ Set PINECONE_API_KEY and PINECONE_ENVIRONMENT
□ Set MySQL credentials (DB_HOST, DB_USER, DB_PASSWORD, DB_NAME)
□ Generate and set JWT_SECRET_KEY
□ Run: pip install -r requirements.txt
□ Run: python -m uvicorn app:app --reload --port 8000

.NET Backend Setup (if using):
□ Update server/AnalyticsChatbot.API/appsettings.json
□ Set OpenAI.ApiKey
□ Set ConnectionStrings.DefaultConnection
□ Set JwtSettings.SecretKey
□ Run: dotnet run

Frontend Setup:
□ Run: cd frontend && npm install
□ Run: npm start
□ Access: http://localhost:3000

Database Setup:
□ Install MySQL 8.0+
□ Create database: CREATE DATABASE helpdesk_db;
□ Run migrations (automatic on first start)
□ (Optional) Load sample data


================================================================================
SECTION 10: COMMON CONFIGURATION ISSUES & SOLUTIONS
================================================================================

Issue: "ModuleNotFoundError: No module named 'pymysql'"
Solution: pip install pymysql

Issue: "OpenAI API key not found"
Solution: Verify OPENAI_API_KEY is set in backend/.env

Issue: "Database connection failed"
Solution: Check MySQL is running and credentials are correct

Issue: "Pinecone index not found"
Solution: Create index with dimension 1536 at pinecone.io

Issue: "JWT token invalid"
Solution: Ensure JWT_SECRET_KEY matches between sessions
