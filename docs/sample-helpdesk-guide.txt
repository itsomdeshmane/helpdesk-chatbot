# AI Helpdesk System - User Guide

## Welcome to the AI Helpdesk System

This AI-powered helpdesk system is designed to help users find answers to their questions quickly and efficiently using advanced natural language processing and retrieval-augmented generation (RAG).

## How It Works

The helpdesk system uses the following technologies:
- **FastAPI Backend**: Handles API requests and document processing
- **React Frontend**: Provides an intuitive chat interface
- **OpenAI GPT**: Generates intelligent responses based on your documentation
- **Pinecone Vector Database**: Stores and retrieves relevant document chunks
- **RAG (Retrieval-Augmented Generation)**: Combines search with AI generation for accurate answers

## Getting Started

### For Users
1. Open the chat interface in your web browser
2. Type your question in the input field
3. Press Enter or click Send
4. Wait for the AI to search the documentation and provide an answer

### For Administrators
1. Add documentation files to the `docs` folder in the project root
2. Supported formats: PDF, Word (DOCX), and Excel (XLSX)
3. Restart the backend server to load new documents automatically
4. Or use the reload API endpoint without restarting

## Features

### Multi-Tenant Support
The system supports multiple tenants, allowing you to segregate documentation by organization or department.

### Module-Based Organization
Documents can be organized by modules (e.g., Finance, HR, IT Support) for better categorization.

### Intelligent Search
The system uses semantic search to find the most relevant information, not just keyword matching.

### Context-Aware Responses
Responses are generated based on actual documentation content, reducing hallucinations.

## API Endpoints

### Chat Endpoint
- **URL**: `/chat/query`
- **Method**: POST
- **Parameters**: 
  - `query`: Your question
  - `tenant_id`: Your organization ID

### Document Upload
- **URL**: `/documents/upload`
- **Method**: POST
- **Parameters**:
  - `file`: The document file
  - `module`: Module name
  - `tenant_id`: Organization ID

### Document Reload
- **URL**: `/documents/reload`
- **Method**: POST
- **Parameters**:
  - `tenant_id`: Organization ID (optional)
  - `module`: Module name (optional)

## Configuration

### Environment Variables
Create a `.env` file in the backend directory with:
- `OPENAI_API_KEY`: Your OpenAI API key
- `PINECONE_API_KEY`: Your Pinecone API key
- `PINECONE_INDEX_NAME`: Your Pinecone index name

### Setting Up Pinecone
1. Create a free account at pinecone.io
2. Create a new index with:
   - Dimensions: 1536 (for OpenAI embeddings)
   - Metric: Cosine similarity
3. Add your API key and index name to `.env`

## Troubleshooting

### No Answers Found
- Ensure documentation files are properly loaded
- Check that Pinecone is configured correctly
- Verify your OpenAI API key is valid

### Slow Response Times
- Check your internet connection
- Verify Pinecone index is in the correct region
- Consider upgrading your OpenAI plan if rate-limited

### Upload Errors
- Ensure file format is supported (PDF, DOCX, XLSX)
- Check file is not corrupted
- Verify file size is within limits

## Best Practices

1. **Keep Documentation Updated**: Regularly update files in the docs folder
2. **Use Clear Language**: Write documentation in clear, simple language
3. **Organize by Topic**: Use descriptive filenames and organize by module
4. **Test Queries**: Test common questions to ensure good answers
5. **Monitor Usage**: Keep track of which questions are asked most frequently
